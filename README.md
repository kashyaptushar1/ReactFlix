# ReactFlix

ReactFlix is a React-based web application that simulates a movie streaming interface. The app is developed with modern tools like Vite, Tailwind CSS, and Axios for fast and efficient development, along with a structured component-based layout.

## Project Structure

The folder structure of this project is as follows:

```
ReactFlix/
├── node_modules/           # Dependencies
├── public/                 # Public assets
├── src/                    # Source code
│   ├── components/         # Reusable components
│   │   ├── partials/       # Nested partial components
│   │   ├── Dropdown.jsx    # Dropdown menu component
│   │   ├── Header.jsx      # Header component
│   │   ├── HorizontalCards.jsx # Horizontal card layout for movies/shows
│   │   ├── Sidenav.jsx     # Sidebar navigation
│   │   └── Topnav.jsx      # Top navigation bar
│   ├── Home.jsx            # Home page component
│   ├── utils/              # Utility functions and helpers
│   │   └── axios.jsx       # Axios instance for API calls
│   ├── App.jsx             # Root component
│   ├── index.css           # Global CSS styles
│   ├── main.jsx            # Entry point for the application
├── .gitignore              # Git ignore file
├── eslint.config.js        # ESLint configuration
├── index.html              # HTML template for Vite
├── package.json            # Project dependencies and scripts
├── README.md               # Project documentation
├── tailwind.config.js      # Tailwind CSS configuration
├── vite.config.js          # Vite configuration file
└── dist/                   # Production build output (generated by Vite)
```

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd ReactFlix
   ```

3. Install the dependencies:

   ```bash
   npm install
   # or if using yarn
   yarn install
   ```

### Running the App

To start the development server:

```bash
npm run dev
# or if using yarn
yarn dev
```

This command will start the app in development mode and open it in your default browser. Any changes you make will automatically reload.

### Building for Production

To build the app for production:

```bash
npm run build
# or if using yarn
yarn build
```

This command will generate optimized static files in the `dist` directory.

### Vite Configuration

The Vite configuration is defined in `vite.config.js` to optimize development and build setups for React and Tailwind CSS. Here is a standard setup for a Vite project with React and Tailwind CSS support:

```javascript
// vite.config.js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000, // Change the port number if needed
    open: true, // Automatically open the app in the browser
  },
  build: {
    outDir: 'dist', // Output directory for production build
    rollupOptions: {
      // Customize the Rollup build options here
    },
  },
});
```

#### Explanation of Key Vite Configurations

- **plugins**: The `@vitejs/plugin-react` plugin is used to enable JSX syntax and React Fast Refresh for better development experience.
- **server.port**: Specifies the port number for the development server (default: `3000`). You can change this if needed.
- **server.open**: When set to `true`, it automatically opens the app in the default browser after starting the dev server.
- **build.outDir**: Specifies the output directory for the production build (default: `dist`).

Feel free to adjust the Vite configuration based on your project requirements.
